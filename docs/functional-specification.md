# [기능상세] AI 멀티 채널 콘텐츠 배포 시스템 (MCB)

## 1. 멀티 계정 관리 (Multi-Account Management)

**계정 연동 플로우**

1. 사용자가 대시보드에서 "계정 추가" 버튼 클릭
2. 플랫폼 선택 (YouTube / Instagram / TikTok)
3. 해당 플랫폼 OAuth 인증 화면으로 리다이렉트
4. 인증 완료 후 Access Token + Refresh Token 암호화 저장
5. 계정 목록에 추가, 상태 표시 (활성/토큰 만료/오류)

**토큰 자동 갱신 로직**

- Cron Job이 매일 토큰 만료일 확인 (만료 7일 전부터 갱신 시도)
- 갱신 성공: 새 토큰 암호화 저장, 상태 "활성"으로 유지
- 갱신 실패: 상태 "토큰 만료"로 변경, 사용자에게 재인증 알림 (이메일 + 대시보드 알림)
- 3회 연속 실패 시 계정 비활성화, 해당 계정으로의 예약 업로드 일시 중지

## 2. AI 캡션 최적화 (AI Caption Engine)

**"OpenAI GPT-4o의 Vision 및 언어 모델을 결합한 지능형 엔진입니다."**

**플랫폼별 캡션 전략**

| **플랫폼** | **제목/타이틀** | **설명/캡션** | **해시태그** | **특이사항** |
| --- | --- | --- | --- | --- |
| **YouTube** | 100자 이내 SEO 키워드 포함 | 5,000자 이내 타임스탬프, CTA 포함 | 최대 30개 관련성 높은 순 | 카테고리 자동 추천 |
| **Instagram** | - | 2,200자 이내 스토리텔링 형식 | 최대 30개 트렌드 + 니치 태그 | 릴스 커버 텍스트 별도 |
| **TikTok** | - | 300자 이내 훅 + 트렌드 중심 | 최대 5개 바이럴 해시태그 | 사운드/효과 추천 |

**AI 캡션 생성 플로우**

1. 사용자가 영상 또는 이미지(최대10장) 업로드 + 기본 설명 입력
2. OpenAI에 플랫폼별 프롬프트 전송 (3개 플랫폼 동시 생성)
3. 각 플랫폼에 맞는 캡션 초안 생성 후 미리보기 표시
4. 사용자가 수정 또는 재생성 가능
5. 확정 후 업로드 진행

**캡션 프리셋**

사용자가 자주 사용하는 캡션 스타일을 프리셋으로 저장할 수 있습니다. 예를 들어 "제품 리뷰형", "튜토리얼형", "이벤트 홍보형" 등의 템플릿을 만들어 두면 반복 작업 시 효율이 높아집니다.

## 3. 최적 시간 자동 업로드 (Smart Scheduler)

**시간 최적화 로직 (3단계)**

1. **1단계 - 통계 기반 추천:** 초기에는 플랫폼별 일반적인 최적 시간 통계 데이터를 기반으로 추천합니다.
2. **2단계 - 계정별 분석:** 각 계정의 과거 게시물 성과 데이터(조회수, 좋아요, 댓글)를 분석하여 계정별 최적 시간을 학습합니다.
3. **3단계 - AI 예측:** OpenAI를 활용하여 콘텐츠 유형, 계정 특성, 요일/시즘성을 종합 분석해 최적 업로드 시간을 예측합니다.

**예약 업로드 처리 흐름**

1. 사용자가 "최적 시간 자동" 선택 또는 직접 시간 지정
2. 선택된 계정별로 최적 시간 계산 (AI 분석)
3. BullMQ에 예약 작업 등록 (delayed job)
4. 예약 시간 도래 시 Worker가 업로드 실행
5. 성공/실패 결과 기록 및 사용자 알림

## 4. 화면 구성 (UI/UX Layout)

### 4.1 화면 목록

| **No** | **화면명** | **주요 기능** | **비고** |
| --- | --- | --- | --- |
| 1 | **로그인/회원가입** | 이메일/소셜 로그인, 회원가입 | Supabase Auth 연동 |
| 2 | **대시보드** | 업로드 현황, 계정 상태, 최근 활동 | 메인 화면 |
| 3 | **계정 관리** | 플랫폼별 계정 추가/삭제/상태 확인 | 토큰 상태 모니터링 |
| 4 | **업로드 생성** | 영상/이미지 업로드 + 계정 선택 + AI 캡션 + 예약 | 핵심 화면 |
| 5 | **업로드 목록/상세** | 업로드 이력, 상태, 계정별 결과 확인 | 필터/검색 지원 |
| 6 | **캡션 프리셋 관리** | AI 캡션 템플릿 생성/수정/삭제 | 캡션 스타일 커스터마이징 |
| 7 | **분석/통계** | 계정별 성과 데이터, 최적 시간 분석 결과 |  |
| 8 | **설정** | 프로필, 알림 설정, API 키 관리 | 관리자 설정 |

### 4.2 핵심 화면 상세 - 업로드 생성 화면

업로드 생성 화면은 4개 스텝으로 구성됩니다.

1. **Step 1 - 영상 또는 이미지(최대10장) 업로드:** 드래그&드롭 또는 URL 입력으로 영상 또는 이미지(최대10장) 업로드. 썸네일 자동 생성. 영상 미리보기 및 기본 정보(파일명, 용량, 길이) 표시.
2. **Step 2 - 계정 선택:** 연동된 계정 목록에서 체크박스로 업로드할 계정 선택. 플랫폼별 그룹핑 표시. 토큰 만료/오류 계정은 비활성화 상태로 표시.
3. **Step 3 - AI 캡션:** 기본 설명 입력 → AI가 플랫폼별 캡션 자동 생성. 탭으로 YouTube/Instagram/TikTok 캡션 미리보기. 각 플랫폼별 수정 가능. 캡션 프리셋 선택/적용 기능.
4. **Step 4 - 예약 및 업로드:** "즉시 업로드" 또는 "예약 업로드" 선택. 예약 시 "최적 시간 자동" 또는 "직접 지정" 선택. 계정별 업로드 상태 실시간 표시 (대기/진행중/완료/실패).

## 5. API 연동 상세 (API Deep Dive)

### 5.1 YouTube Data API v3

- **업로드:** insert — 영상 또는 이미지(최대10장) + 메타데이터 설정
- **예약:** insert의 publishAt 파라미터로 예약 게시 (status: private → 예약 시간에 public)
- **할당량:** 일 10,000 units (영상 또는 이미지(최대10장)는 1,600 units 소모)
- **제한:** 일일 업로드 수 제한 있음 (6개 계정 × 6개 = 약 36건/일)

### 5.2 Instagram Graph API

- **업로드:** POST /me/media → POST /me/media_publish (2단계)
- **지원 형식:** 릴스(Reels), 이미지, 캐러셀 (영상은 리스로 업로드)
- **예약:** API 예약 게시 미지원 — BullMQ delayed job으로 예약 처리
- **제한:** 비즈니스/크리에이터 계정 필수, Meta 앱 심사 필요

### 5.3 TikTok Content Posting API

- **업로드:** POST /v2/post/publish/video/init → chunk upload → publish
- **지원 형식:** 영상 (mp4, 최대 4GB, 최대 10분)
- **예약:** API 예약 게시 미지원 — BullMQ delayed job으로 처리
- **제한:** API 접근 승인 필요, 승인 난이도 높음

### 5.4 대안: 서드파티 API 우회

Instagram과 TikTok의 공식 API 승인이 어려울 경우, Buffer API 또는 Hootsuite API를 통해 우회 연동하는 방안을 병행 검토합니다. 이 경우 추가 구독 비용이 발생할 수 있습니다.
