# 업로드 생성 플로우 (5-Step Wizard)

## 플로우 개요

업로드 생성 화면은 5개 스텝으로 구성된다. 기존 4스텝에서 **계정 선택을 최우선으로 올리고**, **최종 검토 단계를 추가**한 구조다. 계정(플랫폼)이 먼저 확정되어야 이후 파일 검증 조건, AI 캡션 생성 대상, 예약 옵션이 결정되기 때문이다.

```
Step 1 계정 선택 → Step 2 미디어 업로드 → Step 3 캡션 작성 → Step 4 최종 검토 → Step 5 예약 및 업로드
```

---

## Step 1 — 계정 선택

사용자가 콘텐츠를 배포할 플랫폼 계정을 선택하는 단계. 이 단계에서 선택된 플랫폼 조합이 이후 모든 스텝의 동작 조건을 결정한다.

- 연동된 계정 목록을 플랫폼별(YouTube / Instagram / TikTok)로 그룹핑하여 표시
- 각 계정을 체크박스로 선택 (복수 선택 가능)
- 토큰 만료 또는 오류 상태인 계정은 비활성화 처리하고 상태 뱃지 표시 (활성 / 토큰 만료 / 오류)
- 최소 1개 이상의 계정을 선택해야 다음 스텝으로 진행 가능
- 선택 결과는 `selectedAccounts` 배열로 다음 스텝에 전달되며, 여기서 `selectedPlatforms` (중복 제거된 플랫폼 목록)도 파생된다

---

## Step 2 — 미디어 업로드

선택된 플랫폼의 업로드 제약 조건에 맞춰 파일을 업로드하고 검증하는 단계.

### 업로드 방식
- 드래그 앤 드롭 영역 제공
- 영상 1개 또는 이미지 최대 10장 업로드 가능
- 업로드된 파일은 Supabase Storage에 저장하고, public URL을 확보한다 (Instagram API가 공개 URL을 요구하기 때문)

### 파일 검증
- 선택된 플랫폼 중 가장 엄격한 조건을 기준으로 검증
- 검증 실패 시 어떤 플랫폼의 어떤 조건에 위배되는지 구체적으로 안내
- TikTok만 선택한 경우 이미지 업로드 불가 안내 (TikTok Content Posting API는 영상만 지원)

### 플랫폼별 권장 업로드 사양

| 항목 | 일반 영상 | Shorts |
|------|----------|--------|

| 포맷 | MP4 (H.264 + AAC) 권장. MOV, AVI, WMV, WebM, MPEG-2 등도 지원 | MP4, MOV |
| 프레임레이트 | 촬영 원본 유지 (24/25/30/60fps). YouTube는 최대 60fps 지원 | 30fps 또는 60fps |
| 최대 파일 크기 | 256GB (인증된 계정 기준) | 60MB |
| 최대 길이 | 12시간 (인증된 계정), 미인증 15분 | 60초 |
| 썸네일 | 1280×720, JPG/PNG/GIF, 최대 2MB | 자동 생성 |

| 항목 | 영상 |
|------|------|

### 공통 검증 규칙

```
파일 업로드 시 아래 순서로 검증한다:

1. 파일 포맷 확인 — 선택된 모든 플랫폼이 지원하는 포맷인지
2. 파일 크기 확인 — 선택된 플랫폼 중 가장 작은 제한 기준 적용
3. 해상도/비율 확인 — 권장 사양 미충족 시 경고(업로드 차단은 아님)
4. 영상 길이 확인 — 플랫폼별 최대 길이 초과 여부
5. TikTok 포함 시 영상 전용 — 이미지만 업로드한 경우 TikTok 계정 제외 안내
```

### 미리보기 표시 항목
- 썸네일 자동 생성 (영상: 첫 프레임 캡처, 이미지: 원본 축소)
- 파일 기본 정보: 파일명, 용량, 해상도, 비율
- 영상인 경우: 길이, 코덱, 프레임레이트
- 플랫폼별 적합성 뱃지: 각 플랫폼 아이콘 + ✅ 적합 / ⚠️ 경고(권장 미충족) / ❌ 부적합(업로드 불가)

## Step 3 — 캡션 작성

선택된 플랫폼별로 캡션을 작성하는 단계. **AI 자동 생성**과 **직접 작성** 두 가지 모드를 제공하며, 두 모드는 상호 전환 가능하다.

### 작성 모드 선택
- 상단에 **"AI 자동 생성 / 직접 작성"** 토글 배치
- 기본값은 "AI 자동 생성"
- 모드 전환 시 기존 작성 내용을 유지할지 묻는 확인 다이얼로그 표시

### AI 자동 생성 모드
1. 기본 설명 입력란 — 콘텐츠에 대한 간단한 설명 또는 키워드 입력
2. 캡션 프리셋 선택 (선택사항) — "제품 리뷰형", "튜토리얼형", "이벤트 홍보형" 등 저장된 프리셋 드롭다운
3. "캡션 생성" 버튼 클릭 시 OpenAI GPT-4o에 요청
   - Vision: 업로드된 영상/이미지를 분석하여 콘텐츠 맥락 파악
   - 선택된 플랫폼만 대상으로 캡션 생성 (예: Instagram + TikTok만 선택 시 YouTube 캡션은 생성하지 않음)
   - 플랫폼별 캡션 전략 적용 (글자수 제한, 해시태그 수, 형식)
4. 생성 완료 후 플랫폼별 탭으로 결과 표시
5. "재생성" 버튼으로 다시 생성 가능

### 직접 작성 모드
1. 선택된 플랫폼별 탭에 빈 입력 필드 표시
2. 각 탭에 제목(YouTube만), 설명/캡션, 해시태그 입력란 분리
3. "다른 플랫폼에서 복사" 버튼 — 한 플랫폼에 작성한 내용을 다른 탭에 복사
4. 직접 작성 중에도 "AI로 생성해보기" 버튼을 통해 AI 모드로 전환 가능

### 공통 편집 기능 (모드 무관)
- 플랫폼별 탭 UI — 선택된 플랫폼만 탭으로 표시
- 글자수 실시간 카운터 (플랫폼별 제한 대비 현재 글자수)
  - YouTube 제목: 100자, 설명: 5,000자
  - Instagram 캡션: 2,200자
  - TikTok 캡션: 300자 (4,000자 - 2024년 확장, 확인 필요)
- 해시태그 입력 및 카운터
  - YouTube: 최대 30개
  - Instagram: 최대 30개
  - TikTok: 최대 5개 권장 (바이럴 해시태그 중심)
- 글자수 초과 시 경고 표시 (빨간색 카운터 + 경고 메시지)
- 각 플랫폼 캡션을 개별적으로 수정 가능

### 플랫폼별 캡션 전략 (AI 생성 시 프롬프트 참조)

| 플랫폼 | 제목/타이틀 | 설명/캡션 | 해시태그 | 특이사항 |
|--------|-----------|----------|---------|---------|
| YouTube | 100자 이내, SEO 키워드 포함 | 5,000자 이내, 타임스탬프·CTA 포함 | 최대 30개, 관련성 높은 순 | 카테고리 자동 추천 |
| Instagram | — | 2,200자 이내, 스토리텔링 형식 | 최대 30개, 트렌드 + 니치 태그 | 릴스 커버 텍스트 별도 |
| TikTok | — | 300자 이내, 훅 + 트렌드 중심 | 최대 5개, 바이럴 해시태그 | 사운드/효과 추천 |

## Step 4 — 최종 검토

업로드 실행 전 모든 설정을 한눈에 확인하는 단계. 3개 플랫폼 일괄 배포의 실수를 방지하기 위한 안전장치다.

### 표시 항목
- **미디어 미리보기** — 업로드한 영상/이미지 썸네일
- **계정별 카드 목록** — 선택된 각 계정에 대해:
  - 플랫폼 아이콘 + 계정명
  - 해당 플랫폼 캡션 미리보기 (제목, 본문 앞부분, 해시태그 수)
  - 파일 적합성 상태 (✅ / ⚠️)
- **수정 필요 시** — 각 섹션 옆 "수정" 링크 클릭 시 해당 스텝으로 이동 (이전 스텝 자유 이동 가능)

### 검증
- 모든 계정에 캡션이 작성되었는지 확인
- 글자수 초과 항목이 없는지 확인
- 파일 부적합(❌) 계정이 있으면 해당 계정 제외 또는 파일 변경 안내
- 검증 통과 시 "다음" 버튼 활성화

---

## Step 5 — 예약 및 업로드

업로드 방식을 선택하고 실행하는 최종 단계.

### 업로드 방식 선택
- **즉시 업로드** — 확인 즉시 모든 선택 계정에 업로드 시작
- **예약 업로드** — 날짜/시간을 지정하여 예약
  - **최적 시간 자동** — AI가 계정별 과거 성과 데이터를 분석하여 최적 시간 추천
  - **직접 지정** — 달력 + 시간 피커로 수동 지정 (계정별 개별 시간 설정 가능)

### 업로드 처리 흐름
1. "업로드" 또는 "예약" 버튼 클릭
2. 각 계정별 upload_target 레코드 생성 (DB)
3. BullMQ에 작업 등록 (즉시: 즉시 실행 / 예약: delayed job)
4. Worker가 플랫폼별 API 호출하여 업로드 실행
5. 계정별 업로드 상태 실시간 표시:
   - 대기 → 진행중 → 완료 / 실패
   - 실패 시 에러 메시지 + 재시도 버튼
6. 모든 계정 처리 완료 시 결과 요약 표시
7. 결과 알림 (대시보드 알림 + 이메일)

### 상태 표시 UI
- 계정별 카드에 프로그레스 인디케이터
- 상태 뱃지: 대기(회색) / 진행중(파란색 스피너) / 완료(초록색 체크) / 실패(빨간색 X)
- 전체 진행률 표시 (예: 2/3 완료)
