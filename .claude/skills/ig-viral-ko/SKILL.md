# ig-viral-ko

조사 스킬. 이 팩의 나머지는 쓰고, 이건 가서 본다. 매일 말고 매달 돌린다. 공식은 한 철 간다.
영어판 `ig-viral`의 한국어 각색(원본 고지 `../ig-ko-LICENSE.md`).

도구 하나가 돈다. 공식 분류는 `../ig-reel-ko/hooks_ko.json`, 채점은
`../ig-reel-ko/hookscore_ko.py`를 상대경로로 쓴다. 프로젝트 루트에서:

```bash
python -I .claude/skills/ig-viral-ko/swipe_ko.py captured.tsv          # ~/.claude/instagram/swipe.md 에 기록
python -I .claude/skills/ig-viral-ko/swipe_ko.py captured.tsv --no-write
```

## 이걸 할 가치가 있게 만드는 생각 하나

**조회수 숫자 자체는 근거가 아니다.** 팔로워 200만 계정의 40만 회는 조용한 화요일이다.
팔로워 4천 계정의 40만 회는 뭔가를 찾은 거고, 그 뭔가는 베낄 수 있다.

그래서 전부 **배수**로 줄 세운다: 조회수 ÷ 그 계정 최근 중앙값. 3배 이상이 신호. 1.5배
미만은 그 계정의 평범한 날이고, 숫자가 아무리 커 보여도 가르쳐 주는 게 없다.

계정은 **사용자 계정 크기의 약 10배 안**에서 모은다. 200만 팔로워에서 먹히는 공식은 200만
팔로워라서 먹히는 경우가 많다.

## 1단계: 계정 고르기

계정 6~12개를 사용자에게 받거나, 제안하고 승인받는다:

- **직접 4개** - 같은 업종, 같은 상품, 조금 앞선 계정 (과일 산지 직송몰, 식품몰, 화장품 브랜드, 의류몰).
- **인접 4개** - 다른 업종, 같은 시청자. 업종 안에 퍼지기 전에 형식을 빌려 오는 곳.
- **훨씬 큰 계정 2~4개** - 형식만 본다. 업로드 주기나 말투는 절대 따라 하지 않는다.

사용자에게 자기 **저장됨 컬렉션**을 열어 달라고 한다. 가장 빠르고 관련 높은 자료이고, 이미
사용자 취향으로 걸러져 있다.

## 2단계: 가서 보기

이 세션에 실제로 있는 브라우징 도구를 쓴다: 앱 안 브라우저, 사용자 크롬에 붙은 확장, 컴퓨터
사용 도구. API는 없고 필요도 없다. 읽을 만큼의 양이다.

**협상 불가 규칙:**

- **사용자 대신 인스타에 로그인하지 않고, 비밀번호를 절대 묻지 않는다.** 로그인이 필요한
  페이지면 이미 로그인해 있는 건 사용자다. 사용자가 있는 자리에서 그 브라우저를 움직이거나,
  붙여 넣어 달라고 한다.
- **이건 읽기지 스크래핑이 아니다.** 계정 10개, 각 십여 개 릴스, 사람 속도로. 대량 자동 수집은
  인스타 이용약관 위반이고 계정이 활동 제한을 먹는다. 크롤러를 만들지 않고, 스크래핑 서비스를
  쓰지 않고, 백그라운드에서 반복 돌리지 않는다.
- **영상이 아니라 공식을 베낀다.** 훅 모양, 구조, 길이, 컷 패턴. 그들의 대본, 목소리, 편집은
  아니다. 스와이프 파일의 모든 행에 출처 계정을 적는다.

**릴스마다 적을 것** (그 계정의 말 그대로):

| 항목 | 메모 |
| --- | --- |
| account (계정) | 아이디 |
| followers (팔로워) | 프로필에서 |
| median (중앙값) | 최근 릴스 12개를 훑어 가운데 조회수 |
| views (조회수) | 이 릴스. "1.2만", "41만"처럼 적어도 된다 |
| hook (훅) | 첫 줄, 말이든 화면이든, 맞춤법 틀린 것까지 그대로 |
| on-screen | 첫 화면 문구가 다르면 |
| length | 초 |
| cta | 끝에 뭘 요청했나 |

중앙값이 핵심이다. 없으면 다시 팔로워 수로 줄 세우게 되고, 그걸 막으려고 이 스킬이 있다.

**인스타가 충분히 안 보여 줄 때:** 같은 훅 문법이 유튜브 쇼츠에서도 돈다. 조회수와 자막이
공개되어 있고 로그인이 필요 없다. 정당한 보조 자료이고, 말 훅을 얻기가 더 쉽다:

```bash
# 채널 쇼츠의 조회수
python -m yt_dlp --flat-playlist --playlist-end 40 -J \
  "https://www.youtube.com/@HANDLE/shorts" > channel.json

# 쇼츠 하나의 첫 마디, 자동 한국어 자막에서
python -m yt_dlp --skip-download --write-auto-subs --sub-langs "ko.*" \
  --sub-format json3 -o hook "https://www.youtube.com/watch?v=VIDEO_ID"
```

타임스탬프 3.0초 미만인 자막 조각을 다 모은다. 그게 쓰인 대로가 아니라 말한 대로의 훅이다.
한국어 자동 자막은 띄어쓰기·조사가 틀리기 쉬우니 영상을 들으며 한 번 고친다.
(이 명령은 사용자가 요청하고 승인할 때만, 소량으로 돌린다.)

## 3단계: 줄 세우기

탭 구분 파일에 머리줄과 함께 채우고 스크립트를 돌린다. 열 이름은 영어·한국어 둘 다 된다:

```
계정	팔로워	중앙값	조회수	훅
@someone	48000	11000	41만	아무도 안 알려주는 귤 고르는 법
```

```bash
python -I .claude/skills/ig-viral-ko/swipe_ko.py captured.tsv
```

배수를 계산하고, `/ig-reel-ko`가 쓰는 26개 한국어 공식으로 훅 이름을 붙이고, `hookscore_ko.py`로
훅마다 채점하고, 상위 1/3과 하위 1/3을 가르는 것(공식, 훅 점수, 어절·음절 길이, 숫자·이름
든 비율)을 찍고, 미분류 목록을 따로 보여 준다.

## 4단계: 무슨 뜻인지, 조심해서

딱 세 가지만 보고한다:

1. **상위 1/3에 몰린 공식**, 개수와 함께. 계정 6개에 걸쳐 공식 둘이 각 4번이면 발견이다.
   하나가 2번이면 아니다.
2. **상위 1/3이 구조적으로 공유하고 하위 1/3에 없는 것**: 훅 길이, 보상이 눈에 보이는지,
   첫 프레임이 움직이는지, 요청이 어디 있는지.
3. **미분류 행.** 분류기가 이름을 못 붙인 훅은 잡음이거나 `hooks_ko.json`에 아직 없는 공식이다.
   손으로 읽는다. 가장 값진 열이고, 스크립트가 개수를 찍는 이유다. 반복되는 모양이면
   `hooks_ko.json`에 공식을 추가하자고 제안한다.

그다음 표본 크기와 확신 정도를 평범한 말로. 계정 6개 릴스 40개는 주장을 받쳐 준다. 12개는
아니다. 그렇게 말하는 게 조사와 별자리 운세의 차이다.

## 5단계: 찍을 거리로 바꾸기

상위 공식 셋에 대해 **사용자 버전**을 쓴다: 사용자 자신의 이야기, 자신의 숫자, 먹히는 모양으로.
공식 번호를 정한 채로 `/ig-reel-ko`에 넘긴다.

"이 릴스처럼 만들어"는 절대 돌려주지 않는다. 내일 말할 수 있는 훅 한 줄을 돌려준다.

## 출력

```
스와이프 파일  ·  릴스 38개  ·  계정 7개  ·  기준: 계정 중앙값

3배 이상
  38.4배  훅 77  #3  아무도 안 알려주는  @acct_a   412,000  (중앙값 10,700)
  11.2배  훅 70  #9  캡처해 가세요       @acct_c   180,000  (중앙값 16,100)
  ...

몰리는 것
  #3 아무도 안 알려주는   상위 1/3에 5번, 하위 0번
  #2 하지 마세요          4번
  훅 길이 중앙값          상위 7어절, 하위 13어절

미분류 (6)
  둘이 같은 모양인데 hooks_ko.json에 없다: 남의 댓글을 소리 내 읽으며 시작하는 훅. 추가할 만하다.

사용자 버전
  #3  "아무도 안 알려주는 샤인머스캣 꼭지 보는 법, 3초면 돼요."
  ...
```

스와이프 파일은 `~/.claude/instagram/swipe.md`에 쓴다(기본값). `/ig-reel-ko`와 `/ig-plan`이
그걸 읽는다. 한 번 돌리고 나면 나머지 팩이 기본값이 아니라 사용자 자신의 근거로 일한다.
가짜·시험 데이터로 돌릴 때는 `--out`으로 다른 곳에 쓰거나 `--no-write`로 진짜 파일을 덮지 않는다.

이 스킬은 아무것도 게시·팔로우·좋아요·메시지하지 않는다. 읽기만 한다.
