# ig-caption-ko

영어판 `ig-caption`의 한국어 각색(원본 고지 `../ig-ko-LICENSE.md`). 도구 하나가 돈다.
프로젝트 루트에서:

```bash
python -I .claude/skills/ig-caption-ko/caption_ko.py caption.txt --handle fruit_cuma
python -I .claude/skills/ig-caption-ko/caption_ko.py caption.txt --handle joongdi --keywords "시카 토너,세안 후 당김"
```

피드가 보여 주는 그대로 상자에 찍는다: 아이디 뒤 2줄(피드)과 1줄(릴스 화면). 그 상자부터 읽어라.
쓴 다른 무엇보다 먼저.

## 보이는 범위 (추정)

한글은 영문보다 글자 폭이 두 배 가까이 넓어서, 영어판의 "125자"를 그대로 쓰면 실제보다 훨씬
많이 보인다고 착각한다. `caption_ko.py`는 줄 폭으로 직접 채워 본다:

- 한 줄 = 한글 약 28자 폭(390pt급 폰, 캡션 글꼴 약 14pt 기준 추정). 공백 0.3, 영문·숫자 0.55.
- 피드: 굵은 아이디 뒤에 이어 2줄, 끝에 "... 더 보기" → 줄바꿈 없는 캡션이면 **공백 포함 약 50자**.
- 릴스 화면: 1줄 → **약 25자**.
- 그래서 **첫 문장은 40자 안에서 끝낸다**(안전선). 좁은 폰·긴 아이디·큰 글꼴에서도 안 잘린다.
- 첫 줄에서 줄바꿈하면 그 줄의 남은 폭은 버려진다. 첫 문장 뒤 바로 줄바꿈하면 피드에서는
  둘째 줄이 거의 안 보인다(대신 첫 문장이 깔끔하게 끊긴다). 의도해서 쓰라.

기기·앱 버전마다 다르다. `--line-width`로 바꿔 시험할 수 있다.

## 먼저, 이 캡션이 무슨 일을 하는지 정한다

이걸 건너뛰면 캡션을 망친다.

**A: 영상이 이미 훅을 했다.** 릴스는 첫 2초에 말과 화면으로 훅을 한다. 캡션은 두 번째 훅이
아니다. 영상과 경쟁하면 둘 다 진다. 캡션의 일은 요청, 그 요청이 말이 되게 하는 맥락, 그리고
사람들이 검색하는 말.

**B: 캡션이 콘텐츠다.** 사진, 단일 이미지, 궁금증을 여는 캐러셀 표지. 이때는 첫 문장이 훅이고
릴스 훅과 똑같이 굴러간다: 구체적이고, 짧고, 문장 중간이 아니라 궁금한 자리에서 끊긴다.

어느 쪽인지 정하고 말하라. 훅이 센 릴스면 A로 쓰고 이유를 말한다.

## 모양

```
첫 문장    40자 안. A: 요청을 그냥 말한다. B: 훅.
           인사 금지, 해시태그 금지, 첫 글자 이모지 금지.
본문       짧은 문단, 문단 사이 빈 줄 하나. 두~여섯 문단. 검색어가 여기 산다.
요청       하나. 댓글 키워드, 저장, DM 중 하나.
해시태그   3개, 맨 아래 따로 한 줄. 또는 없음.
```

한도는 2,200자이고 거의 아무것도 2,200자가 필요 없다. 더 보기를 누르게 하고 600자를 주는
캡션이 1,800자를 주는 캡션을 이긴다.

## 해시태그, 정직하게

해시태그는 더 이상 도달 수단이 아니고, 인스타가 제품 변경으로 그걸 말했다. **2025년 12월
18일부터 게시물당 해시태그 상한이 5개**(전에는 30개)이고, "더 적게(최대 5개), 더 정확한"
태그가 낫다고 공지했다. 이 팩의 규칙은 **3개**, 주제 라벨로만. 4~5개는 경고, 6개 이상은 실패.

`#일상` `#데일리` `#소통` `#맞팔` `#선팔` `#좋아요` `#인친` `#fyp` `#viral`은 아무것도
설명하지 않는다. 뺀다. 대신 `#샤인머스캣` `#세안후당김` `#와이드슬랙스`처럼 상품·고민·품목.

## 검색어가 해시태그보다 중요하다

인스타 검색은 캡션 본문을 읽는다. 찾히고 싶은 말은 **사람이 실제로 칠 법한 문구로, 평범하게
읽히는 문장 안에** 넣는다. "샤인머스캣 고르는 법"을 셋째 줄 문장 속에, `#샤인머스캣고르는법`
태그에만 넣지 말고. 한국어 검색어는 띄어쓰기가 제각각이라 검사기는 공백을 무시하고 맞춰 본다.
해시태그에만 있고 문장에 없으면 경고한다.

검색어 두세 개를 받아서 검사기에 넘긴다:

```bash
python -I .claude/skills/ig-caption-ko/caption_ko.py draft.txt --keywords "샤인머스캣 고르는 법,제철 과일"
```

## 규칙

- **캡션에 링크 금지.** 캡션 링크는 안 눌린다. 본문 속 URL은 "나 이 플랫폼 안 써요"라는 죽은
  글자다. 프로필 링크나 DM으로. (스마트스토어 주소도 같다.)
- **요청은 하나.** 두 개는 없는 것과 같다. `caption_ko.py`가 센다.
- **키워드 댓글은 칠 수 있는 한 단어로.** 공백·이모지 없이, 영상에서도 소리 내어 말한다.
  댓글에 `꼭지`, `순서`, `CICA`는 된다. 댓글에 "피부 타입별 순서 가이드"는 안 된다.
- **링크가 있으면 첫 댓글을 따로 쓴다.** 영수증에 그렇게 적는다.
- **이모지는 장식이 아니라 문장부호처럼.** 100자당 4개 넘으면 경고.
- **대체 텍스트는 20초 값어치가 있다.** 캐러셀·사진이면 쓴다. 화면 낭독기와 인스타가 읽는다.
- **광고 심의.** 화장품·건강기능식품·식품: 치료, 완치, 재생, 염증, 질병 예방, 부작용 없음은
  실패(의약품 오인), 최고·유일·100%·1위·최초는 경고(근거·출처 없으면 뺀다). 효능은 근거 문구
  범위 안에서만, 개인차를 밝힌다. 판매 중이 아닌 상품은 파는 것처럼 쓰지 않는다.

## 순서

1. A인지 B인지 정하고 말한다.
2. 초안을 쓴다.
3. `/ig-human-ko`에 통과시킨다. 캡션은 짧아서 상투어가 어디보다 크게 들린다.
4. 사용자의 검색어와 아이디로 `caption_ko.py`를 돌린다. 실패는 전부 고치고, 경고는 하나씩
   소리 내어 결정한다(조용히 넘기지 않는다).
5. 복사해 쓸 블록을 찍고, 그다음 영수증:

```
캡션 준비됨
일:        A - 릴스가 훅을 한다
보이는 곳: 첫 문장 30자, 피드 2줄 안에 통째로 (안전선 40자)
요청:      하나, 댓글 "꼭지"
해시태그:  3개
검색어:    "샤인머스캣 고르는 법" 셋째 문단, "제철 과일" 둘째 문단
검사:      READY
```

아무것도 올리지 않는다. 사용자가 붙여 넣는다.
