# ig-profile-ko

영어판 `ig-profile`의 한국어 각색(원본 고지 `../ig-ko-LICENSE.md`). 개인 브랜드 기준을
**쇼핑몰 · 브랜드 계정** 기준으로 바꿨고, 채점을 둘로 나눠 같은 프로필을 다시 채점해도 점수가
흔들리지 않게 했다.

대부분 여기서 엉뚱한 걸 고친다. 프로필은 사람들이 둘러보는 진열장이 아니다. 릴스 하나 보고
넘어온 사람이 **3초 안에 정하는 화면**이고, 답할 질문은 하나다: 여기 그런 게 더 있나, 나한테
맞는 곳인가.

## 입력

사용자에게 붙여 넣거나 캡처해 달라고 한다: 이름 칸, 아이디, 소개, 링크가 가는 곳, 하이라이트
이름, 고정 게시물, 첫 9칸 표지. 프로필 윗부분 캡처 + 피드 첫 두 줄이면 첫 채점에 충분하다.

MCB에 연결된 계정이면 아이디 · 이름 · 소개 · 링크 · 계정 종류 · 마지막 게시일 · 최근 게시물
표지는 API로 채워진다. **하이라이트 · 고정 게시물 · 스토리 빈도는 API에 없어서** 사람이 입력한다.

사용자 대신 인스타에 로그인하지 않는다.

## 1. 기계 채점

`rubric_ko.json`의 12개 항목 중 규칙으로 판정되는 7개(고정 게시물, 링크, 하이라이트, 아이디,
카테고리·연락, 최근 활동, 스토리 - 54점)는 스크립트가 점수까지 매긴다. 나머지 5개(46점)는 근거만 모은다.

```bash
python -I .claude/skills/ig-profile-ko/profile_ko.py profile.json          # 표로
python -I .claude/skills/ig-profile-ko/profile_ko.py profile.json --json   # MCB에서 부를 때
```

입력 JSON 형식은 스크립트 맨 위 설명에 있다. 모르는 칸은 빼면 그 항목은 판단 채점으로 넘어간다.
**스크립트가 매긴 점수는 바꾸지 않는다.** 틀렸다고 보이면 입력이 틀린 것이니 입력을 고친다.

## 2. 판단 채점

이름 칸 · 소개 첫 줄 · 소개 나머지 · 피드 첫 9칸 · 프로필 사진은 `rubric_ko.json`의 만점 기준과
흔한 실패를 보고 매긴다. 스크립트 findings(글자 수, 광고 금지 표현, 키워드 묶음)를 근거로 쓴다.

- **정직하게.** 처음 채점하면 대부분 30~40점대다. 후한 점수는 쓸모없다.
- **계정 역할에 맞춰서.** MCB 계정 연동의 역할(상품 중심 / 사람 중심)을 따른다. 역할을 모르면
  묻는다. 계정을 직접 보지 않고 역할을 짐작해 정하지 않는다.
- **광고 표현 규칙 위반은 소개 나머지 0~2점.** 최고 · 유일 · 100% · 치료 같은 말, 심의 없는
  건강기능식품 기능성 표현. 고칠 때 MCB 광고 문구 규칙(`get_rules`)으로 다시 확인한다.

```
프로필 점수  38/100

  이름 칸         2/12   브랜드 이름만, 검색되는 상품 단어 없음
  소개 첫 줄      3/12   '프리미엄 | 신선 | 정직' - 키워드 묶음
  고정 게시물 3개  0/10   고정 없음
  하이라이트       2/8    '일상', '2023'
  피드 첫 9칸      4/8    9칸 중 6칸이 글자 없는 근접 사진
  ...
```

## 3. 다시 쓰기 (이 순서로)

잃은 점수가 큰 순서로 고친다. 한 번에 다 고치지 않는다 - 사용자가 하나씩 직접 바꿔야 한다.

**1. 이름 칸 (30자).** 굵은 글씨 줄, 아이디 아님. 인스타 검색이 읽는 칸인데 대부분 이름만 넣는다.
형식: `{브랜드} | {검색되는 상품 단어}` - 예: `오늘과일 | 제철 과일 산지직송`. 3개 안을 준다.

**2. 소개 첫 줄.** 누구에게 무엇을 주는 곳인지. 회사 소개 문구 · 형용사 · 막대로 이은 키워드가
아니다. 나머지 150자에는 확인된 증거 하나 또는 분명한 혜택 하나.

**3. 고정 게시물 3개.** 세 자리, 세 가지 일: 가장 강한 증거(후기 · 실사용), 사는 법이 가장 분명한
것, 브랜드나 사람 소개. 프로필 전체에서 가장 효과가 큰 수정이고 네 번 누르면 끝난다.

**4. 하이라이트.** 4~6개, 사는 사람이 묻는 질문 이름으로: 주문방법 · 배송 · 후기 · 상품정보 ·
이벤트. '일상' 같은 건 지운다.

**5. 링크.** 소개가 방금 약속한 것과 맞는 목적지 하나. 둘부터는 메뉴다.

**6. 피드 표지.** 첫 9칸을 썸네일 크기로 본다. 릴스 표지는 골라서 정하고, 표지에 한국어 4~8자.

## 출력

점수 표 → 고칠 순서대로 바로 붙여 넣을 수 있는 문구 → 다시 채점한 점수와 차이. 문구는 모두
`/ig-human-ko`로 AI 티를 걷고 보여 준다. 다시 쓴 결과가 98이 아니라 84면 84라고 하고, 나머지에
무엇이 필요한지 말한다 - 보통은 피드, 스토리 습관, 아직 없는 고정 게시물이고 문구로 해결되지 않는다.

이 스킬은 인스타에 아무것도 저장하지 않는다. 각 칸은 사용자가 직접 고친다.
