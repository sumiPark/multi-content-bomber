# ig-reel-ko

아이디어 하나를 끝까지 보게 되는 릴스로 바꾼다. 영어판 `ig-reel`의 한국어 각색이다
(원본 고지는 `../ig-ko-LICENSE.md`).

이 폴더의 도구 둘은 실제로 돈다. 쓰라. 훅을 눈대중으로 고르지 말고 길이를 짐작하지 마라.
Windows는 `python`, macOS·Linux는 `python3`. 프로젝트 루트에서:

```bash
python -I .claude/skills/ig-reel-ko/hookscore_ko.py hooks.txt               # 훅 여러 개 순위
python -I .claude/skills/ig-reel-ko/hookscore_ko.py --hook "한 줄"          # 하나만 채점
python -I .claude/skills/ig-reel-ko/beats_ko.py script.txt --target 20      # 찍기 전 비트 시트
```

## 쓰기 전에

1. `~/.claude/instagram/voice.md`가 있으면 읽는다. 사용자가 카메라 앞에서 어떻게 말하는지,
   절대 안 하는 말, 누구에게 말하는지가 있다. 없으면 그 계정 릴스 **세 개**를 받아 말투를
   추론하고 파일을 쓴다. 틀린 말투의 대본은 못 쓴다. 소리 내어 말해야 하니까.
   존댓말(해요체)인지 반말인지, 어미 습관(~거든요, ~더라고요)까지 적어 둔다.
2. 이 폴더의 `hooks_ko.json`을 읽는다. 공식 26개, 각각 템플릿·예시·화면 문구·쓰는 상황·
   망치는 방식이 있다. 예시는 우리 상품군(과일·식품·화장품·의류)으로 써 뒀다.
3. 아이디어가 얇으면 부풀리지 마라. 한 번에 묻는다: 무슨 일이 있었나, 누구에게, 얼마가
   들었거나 남았나. 릴스에는 구체적이고 사실인 것 하나가 필요하다.
4. `~/.claude/instagram/swipe.md`가 있으면 읽는다. `/ig-viral-ko`가 쓰는 파일이고, 지금 이
   업종에서 어떤 공식이 먹히는지에 대한 사용자 자신의 근거다. 이 파일의 기본값보다 우선한다.
5. 상품 사실(성분, 함량, 산지, 당도, 가격)은 상품 데이터(상품 MCP·상세페이지 분석 등 쓸 수
   있는 것)에서 확인한 것만 쓴다. 확정된 심의 문구가 있으면 그 문구를 넘지 않는다.

## 모양

릴스는 처음 2초에 정해지고 다음 5초에 붙잡힌다.

```
0:00 - 0:02   훅          주장. 말 훅과 화면 훅을 따로 쓴다. 첫 프레임에 움직임.
0:02 - 0:07   걸린 것     이게 보는 사람에게 왜 중요한지. 한 줄.
0:07 - ...    본론        비트 하나에 생각 하나, 비트마다 화면이 바뀐다.
마지막 3초    보상        훅이 약속한 걸 준다. 그다음 요청 하나.
마지막 줄     루프        훅의 말 하나를 되받아 다시 재생이 자연스럽게.
```

길이: 15~45초가 일하는 범위. 릴스는 3분까지 되지만 거의 아무도 그럴 필요 없다. 7초 미만은
반복 재생 수만 부풀고 다른 건 안 는다.

## 순서

**1. 훅 셋.** `hooks_ko.json`에서 아이디어에 진짜 맞는 공식 셋을 고르고, 각각 말 훅과 화면
훅을 쓴다. 한 공식을 세 번 바꿔 쓴 게 아니라 다른 공식 셋.

**2. 채점.** 말 훅 세 줄을 파일에 한 줄씩 넣고 `hookscore_ko.py`를 돌린다. 순위를 사용자에게
보여 준다. 1등이 50점 아래면 아직 훅이 없는 거다. 다듬어서 해결되지 않는다.

**3. 대본.** 이긴 훅으로. 사용자가 실제로 말하는 대로, 짧은 문장, 연습해야 하는 문장은 없이.
글말(~함, ~하였습니다, ~에 있어서)이 아니라 입말.

**4. 시간.** `beats_ko.py script.txt --target {길이}`. 경고를 다 고친다: 3초 넘는 훅,
4초 넘는 비트, 구체적인 게 없는 비트 연속, 루프 없음. 깨끗해질 때까지 다시 돌린다.
기본 말속도는 6.5음절/초(추정). 사용자가 직접 재 본 값이 있으면 `--sps`로.

**5. 휴머나이즈.** 보여 주기 전에 `/ig-human-ko`에 통과시킨다. 글로 쓴 티는 소리 내는 순간 난다.

**6. 블록 출력.** 대본은 코드 블록, 화면 문구는 시간과 함께 따로 목록, 그리고:

```
릴스 준비됨
훅:         #3 아무도 안 알려주는, 73점 STRONG
길이:       18.2초, 비트 8개, 6.5음절/초
화면 문구:  카드 6장
휴머나이저: 기계 흔적 2개 제거, 사람 점수 81 PASS
캡션:       다음은 /ig-caption-ko

"좋아"라고 하면 기록하고, 아니면 바꿀 걸 말해 줘.
```

**7. 절대 게시하지 않는다.** 이 스킬은 대본을 만든다. 찍고 올리는 건 사용자다. "좋아"면
`~/.claude/instagram/log.md`에 날짜, 쓴 공식, 첫 줄을 덧붙인다(나중에 `/ig-audit`이 쓴다).

## 화면 문구는 별도의 대본이다

매번 따로 쓴다. 들리기 전에 읽힌다.

- **한 카드 12자 안팎(공백 빼고), 두 줄 이내.** 한국 릴스 자막·타이틀 관행. 팔 길이에서,
  아직 소리를 안 켠 사람이 읽는다. 숫자는 아라비아 숫자로(“42만 원”, “20분 → 5분”).
- **훅 카드는 첫 프레임에 이미 떠 있다.** 한 박자 쉬고 나오면 늦다.
- **안전 영역 안에.** 1080x1920 화면에서 y=230 위, y=1440 아래에는 아무것도 두지 않고,
  오른쪽 230px는 비운다. 그 밖은 인터페이스(캡션, 오른쪽 버튼 줄, 음원 표시)가 덮는다.
- **훅을 캡션 자리에 두지 마라.** 화면 아래쪽은 가려진다.
- **본론은 자막을 박는다.** 대부분 무음으로 먼저 본다. 한국 릴스는 자막이 기본값이다.

## 차이를 만드는 규칙

- **릴스 하나에 생각 하나.** 대본에 둘이면 릴스가 둘이다. 그렇게 말하라.
- **형용사 대신 숫자.** "42만 원"이 "엄청"을 이긴다. 숫자가 없으면 지어내지 말고 물어라.
- **인트로를 자른다.** 인사, "오늘은 ~ 소개해 드릴게요", 이름, 로고 없음. 평소라면 6초쯤에
  할 문장에서 시작한다.
- **비트마다 화면을 바꾼다.** 8초 고정 샷이 사람이 나가는 자리이고 `beats_ko.py`가 잡는다.
- **요청은 끝에 하나.** 댓글 키워드, 저장, 팔로우 중 하나.
- **절대 지어내지 않는다.** 사용자 이름으로 없는 수치·고객·매출·결과를 쓰지 않는다. 자리
  채움으로도. 필요한데 모르면 대본에 `{{숫자}}`를 남기고 표시한다.
- **광고 심의.** 화장품·건강기능식품·식품은 치료, 완치, 재생, 염증, 최고, 유일, 100%,
  부작용 없음, 질병 예방 같은 말을 대본·화면 문구 어디에도 쓰지 않는다(`hookscore_ko.py`가
  치명적 감점으로 잡는다). 효능은 근거 문구 범위 안에서만, "피부마다 달라요" 같은 개인차를
  밝힌다. 피부 전후 비교는 심의 위험이 커서 피한다. 판매 중이 아닌 상품은 파는 것처럼 쓰지 않는다.
- **쓸 수 없는 유행 음원에 맞춰 쓰지 마라.** 사용자 목소리가 필요하면 그렇다고 말하라.

## 예시

```
/ig-reel-ko 샤인머스캣 꼭지 색으로 신선도 고르는 법 (@fruit_cuma, 20초)
```

```
훅 (채점됨)
  77  STRONG  #3  아무도 안 알려주는  "아무도 안 알려주는 샤인머스캣 고르기, 꼭지 3초"
                                      화면: 아무도 안 알려준 꼭지
  73  STRONG  #23 숫자 하나           "작년 샤인머스캣 반품 10건 중 7건이 꼭지 갈색이었어요"
                                      화면: 반품 10건 중 7건
  50  OK      #26 제일 쉬운 방법      "샤인머스캣 제일 쉽게 고르는 법"
                                      화면: 제일 쉬운 법

#23으로 찍는다: 점수는 #3이 조금 높지만, 반품 숫자는 우리만 가진 사실이고 화면에서 한눈에
읽힌다. (단, 그 숫자가 실제 우리 반품 기록일 때만. 아니면 {{숫자}}로 비워 두고 묻는다.)
```

## 한계 (정직하게)

- `hookscore_ko.py`는 조회수 예측기가 아니다. 인사·서두·숫자 없는 훅·긴 훅을 거르는 데 쓰고,
  괜찮은 훅 둘 중 어느 게 더 퍼질지는 시청 지속 그래프로 판단한다.
- 한국어판 가중치·사전은 직접 만든 샘플로만 맞췄다. 실제 한국어 릴스 코퍼스로 검증한 적 없다.
- 음절/초(6.5)와 구체 명사 사전(품종·산지·성분)은 추정·예시다. 사용자 계정 데이터로 고쳐 써라.
